# Project Aegis

Project Aegis is a next-generation desktop security monitoring application designed for Linux systems. It provides enterprise-grade threat detection, machine-learning anomaly scoring, and automated mitigation, all managed through a beautiful, native desktop dashboard.

Project Aegis acts as your personal Security Operations Center (SOC), continuously watching your system in the background and alerting you to suspicious activity before it can cause harm.

---

## 🧠 How It Works (Working Principle)

Project Aegis operates in four interconnected layers:

1. **The Daemon (Continuous Monitoring)**
   A lightweight background service (`aegis-daemon`) runs continuously as `root`. It monitors system logs (like `/var/log/auth.log`) in real-time, extracts usernames, timestamps, and IP addresses, and tracks authentication failures. It also continuously gathers system telemetry like CPU, RAM, open ports, and active users.

2. **The Machine Learning Engine (Anomaly Detection)**
   Using an LSTM (Long Short-Term Memory) neural network — specifically an Isolation Forest autoencoder — Aegis learns the "normal heartbeat" of your specific system. If the system's telemetry or behavior suddenly deviates from this baseline (e.g., a massive spike in background processes during an odd hour), the ML engine flags an anomaly.

3. **Threat Intelligence & Mitigation (Defense)**
   When a threat is detected (either by a hard rule like a brute-force attack, or a high ML anomaly score), Aegis gathers forensics and queries **AbuseIPDB** to check the attacker's global reputation. It then uses **Groq's LLM** to generate an intelligent verdict. If the threat is severe, Aegis automatically blocks the attacker's IP address using your system's firewall (`ufw`) and sends an instant alert to your **Discord** server.

4. **The Desktop Dashboard (Command Center)**
   The `aegis-dashboard` is a native, premium desktop application that you run as a normal user. It securely reads the data generated by the daemon and provides live charts, incident reports, machine-learning status, and a firewall block manager.

## 🚀 Installation

Project Aegis is packaged as a standard Debian (`.deb`) application for easy installation on Kali Linux, Ubuntu, and other Debian-based systems.

### 1. Prerequisites
Ensure you have the following system utilities installed:
```bash
sudo apt update
sudo apt install rsyslog ufw ssh sshpass dpkg-dev rsync python3-pyside6.qtwidgets -y
```

### 2. Download and Build
Clone the repository and build the `.deb` package:
```bash
git clone https://github.com/Bogzilla007/CapstoneProject.git
cd CapstoneProject
bash build_deb.sh
```

### 3. Install the Application
Install the generated package (the version number may vary):
```bash
sudo apt install ./dist/project-aegis_0.2.3_all.deb
```
*Note: After installation, **log out of your desktop and log back in** (or restart your terminal) so your user account is granted access to the secure `aegis` permission group.*

### 4. Install Python Dependencies
Project Aegis requires a few Python libraries. Install them system-wide so the background daemon can access them:
```bash
sudo python3 -m pip install -r /usr/share/doc/project-aegis/requirements.txt --break-system-packages
```

## ⚙️ Configuration

Before Aegis can fully protect your system, it needs access to a few external APIs for threat intelligence and alerting. 

1. Open the configuration file:
   ```bash
   sudo nano /etc/project-aegis/config.py
   ```
2. Fill in your API keys:
   - `GROQ_API_KEY`: Get this from [console.groq.com](https://console.groq.com/)
   - `DISCORD_WEBHOOK_URL`: Create a webhook in your Discord server settings.
   - `ABUSEIPDB_API_KEY`: Get this from [abuseipdb.com](https://www.abuseipdb.com/)
3. Start the background monitor:
   ```bash
   sudo systemctl enable --now aegis-daemon
   ```

## 🤖 Training the AI Model

When you first install Project Aegis, the Machine Learning engine will be in the `GATHERING` phase. It needs to learn what your system looks like when it is functioning normally.

1. **Collect Baseline Data:**
   Run the data collector. This will record your CPU, RAM, and port activity.
   ```bash
   sudo aegis-collect-baseline
   ```
   *Let this command run for at least 15 to 30 minutes while you use your computer normally (or leave it idle). Then press `Ctrl+C` to stop it.*

2. **Train the Neural Network:**
   Generate the AI model based on the data you just collected:
   ```bash
   sudo aegis-train-model
   ```

3. **Activate the AI:**
   Restart the background daemon to load your newly minted AI model into active memory:
   ```bash
   sudo systemctl restart aegis-daemon
   ```

## 🖥️ Using the Dashboard

To open the SOC Command Center, simply search for **Project Aegis** in your application menu, or run this in your terminal:
```bash
aegis-dashboard
```

- **Overview:** Live CPU/RAM gauges and total incident counts.
- **Incidents:** Feed of recent attacks, their severity, and AI-generated summaries.
- **ML Status:** Live anomaly scoring chart and neural network metadata.
- **Timeline:** Visual breakdown of attacked usernames and top offending IPs.
- **Block Manager:** View active firewall blocks and manually whitelist IPs.

## 🔄 Updating Project Aegis

To update the application to the newest version, simply pull the latest code and reinstall the `.deb` package:

```bash
cd CapstoneProject
git pull
bash build_deb.sh
sudo apt install ./dist/project-aegis_*.deb
sudo systemctl restart aegis-daemon
```
